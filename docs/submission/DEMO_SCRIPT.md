# VOLTRO 심사 시연 대본

약 3분 구성. 오프라인 데모의 수치와 실제 SDK·도로 모드의 수치를 혼용하지 않는다. 시연 중 키보드 입력을 줄이도록 앱의 시나리오 메뉴를 사용한다.

| 구간 | 화면과 조작 | 설명 |
|---|---|---|
| 0:00–0:20 | Home, 차량 입력과 출처 확인 | “시간과 배터리를 함께 보고 경로를 고르는 앱입니다. 이 시연은 데모 차량값을 사용합니다.” |
| 0:20–0:45 | 심사 시연 시나리오 → 절전 전환 → 준비 | “강릉 합성 경로를 비교합니다. 절전 경로는 15분 더 걸리지만 계산상 약 2.9 kWh 덜 씁니다. 추천 조건과 전비 저하 가정도 확인할 수 있습니다.” |
| 0:45–1:05 | 빠른 경로가 선택된 상태에서 주행 시작, 분기점 | “같은 분기점 이후의 시간과 에너지를 비교합니다. 재생은 선택을 기다리며 일시정지하고, 승인해야 경로가 바뀝니다.” |
| 1:05–1:25 | 절전 경로로 변경 → 완료 리포트 | “도착 리포트는 출발 경로와 완료 경로의 계산상 차이를 보여줍니다. 실제 에너지 절약 성능을 측정한 수치는 아닙니다.” |
| 1:25–1:50 | 새 여정 → 시나리오 → 배터리 부족 | “최소 도착 잔량에 못 미치면 시작할 수 없습니다. 필요한 출발 SOC와 추가 배터리 에너지를 설명하며 임계값을 자동으로 낮추지 않습니다.” |
| 1:50–2:15 | 목적지 다시 선택 → 시나리오 → 변경 실패 → 재생 → 승인 | “변경 요청이 실패하면 기존 경로를 유지합니다. 화면의 안내와 활성 경로를 같이 확인합니다.” |
| 2:15–2:35 | 취소 후 실제 도로 모드 확인 또는 준비된 실제 Pleos 가이드 | “실제 모드에는 OSM 지도와 OSRM 도로 경로를 연결했습니다. 실제 SDK는 SOC snapshot을 읽으며, 주행은 좌표 재생입니다.” |
| 2:35–3:00 | 기술 범위와 다음 실험 설명 | “다음 단계는 국내 도로와 실차 에너지 정확도 검증입니다. 정차 상태 사용성부터 확인하고 차량별 실측 결과로 보정하겠습니다.” |

## 복구 보조 시연

분기점 결정 화면에서 앱 프로세스를 종료한 뒤 재실행한다. Home → **이전 재생 복구**를 누른다. 당시 입력·위치·결정 화면이 복구되고 일시정지 상태가 유지되는지 확인한 뒤 승인한다. 단순 화면 회전과 실제 프로세스 종료를 구분한다. 체크포인트가 없거나 24시간이 지났다면 새 시나리오를 준비한다.

## 현장 준비

인터넷 없이 핵심 가치를 보여줄 때는 세 가지 오프라인 시나리오를 사용한다. 실제 SDK 읽기는 Pleos Vehicle Service가 있는 환경에서만 시연한다. 실제 도로 모드는 인터넷을 사용하며 충분한 출발 SOC를 입력해야 할 수 있다. 재설치 직후 SDK timeout은 여전히 관찰 가능한 제약이므로 실제 응답을 확인하고 성공을 미리 단정하지 않는다.
